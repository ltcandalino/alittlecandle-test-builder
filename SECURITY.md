# Security

ALittleCandleTestBuilder stores teachers' accounts and test questions, so security problems matter.

**Please don't report a security problem in a public issue.** Use
[Report a vulnerability](https://github.com/ltcandalino/alittlecandle-test-builder/security/advisories/new)
on the Security tab instead. Only the maintainer sees it.

Fixes go into the newest release; the Docker image is rebuilt and scanned every week. If you run your own
website, keep it up to date with `docker compose pull && docker compose up -d` (see `docker/README.md`).
