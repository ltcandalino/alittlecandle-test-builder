# Courses

Each course (Geometry, Algebra 1, Algebra 2, Pre-Calculus, or any you add) has:
- its own questions
- its own test settings (**2 Arrange**, **3 Format**): document type, numbers, fonts, selected questions

Switch courses with the **Course** menu at the top. Add, rename or delete courses on **Import & backup › Courses** (**Add course**, **Rename**, **Delete**).

When you import, questions go into the course that's currently chosen.

## Using a bank in several courses

A bank can be shared by several courses (for example an Algebra 1 bank you also use in Algebra 2) without making a copy:

1. Import the bank into one course as usual.
2. On **Import & backup › Your banks**, click the bank's **⋯** menu.
3. Under **Also use in**, tick the other courses that should use it.

The questions now show up in each ticked course. There's still only one copy, so fixing a typo or an answer in one course fixes it everywhere. Shared questions show an **Also in …** tag in the question bank. Each course still keeps its own tests and settings.

You can also tick courses for a single question: open it with **Edit**, then **More details → Courses**.

**Deleting:** **Delete** on a shared question only takes it out of the course you're in; the other courses keep it. The same goes for deleting a bank or a whole course. A question is only gone for good when no course uses it any more. **Undo** works as usual.
