# Backups and Sync

## Single-file version

Your work lives in the browser on that computer. To keep it safe:

- **Import & backup → Download backup** saves one `.json` file with all your banks, pictures and settings. Do this now and then, and keep the file somewhere safe (a NAS, Google Drive…).
- **Restore a backup** loads a backup file. Questions you already have are skipped.

Clearing the browser's site data deletes your work, so download a backup first.

## Website version

When you're signed in, your work is saved on the server and follows you to any computer.

- **☁ Synced** at the top means your latest changes are on the server.
- If the internet drops, keep working. It catches up when you're back online. Use **Sync now** to sync right away.
- **Signing out** removes the copy kept in that browser, which is good for shared school computers.

### Moving from the single file to the website

In the single-file app: **Download backup**. On the website, sign in and choose **Restore a backup**. Each colleague does the same with their own backup.
