# Troubleshooting

**The header or footer is missing when I print.**
Use Chrome or Edge, version 131 or newer. In the print window, make sure **Headers and footers** (the browser's own) is off and **Margins** is set to **Default**.

**The lesson headings look plain.**
The lesson headings use Mac fonts (Papyrus, Chalkduster, Bradley Hand, Noteworthy, Baskerville). Computers without them use a similar fallback font.

**My questions disappeared.**
The single-file app saves in one browser on one computer. Check that you opened the same file in the same browser. If you have a backup, use **Restore a backup**.

**"Your browser refused to save."**
The browser is out of storage space or in private mode. Download a backup right away, then free up space or leave private mode.

**A PDF question came in wrong.**
Switch that question to **Picture**, or drag on the page to clip the right area.

**Math from a .bnk looks off.**
Open the question and fix it in the editor. The bank's original file isn't changed.

**The page says it's slowing down Firefox.**
Big PDF imports are faster in Chrome or Edge. Import large PDFs a section at a time.
