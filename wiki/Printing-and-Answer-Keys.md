# Printing and Answer Keys

## Versions and scrambling

Choose 1 to 8 **Versions** (A–H) on **Build & print**. The scrambling choices are under **Page style**.

- **Shuffle question order**: within each part or section
- **Shuffle answer choices**: "All of the above" and "None of the above" stay last
- **Keep Version A in the original order**: handy as your master copy
- **New scramble**: makes a new shuffle. Versions stay the same until you press it, so an answer key always matches copies you've already printed.

## Printing

- **Print … + answer keys**, **… only** or **Answer keys only**
- The browser's print window opens. To make a PDF, choose **Save as PDF** as the printer.
- **Print each version separately**: each version starts at page 1 with its own first-page header. The browser opens one print window per version.

Use **Chrome** or **Edge** (version 131 or newer). Other browsers may leave out the page headers and footers.

## Answer keys

Each version gets its own key, listing every question's answer in that version's order. Bonus questions are listed as *Bonus 1, Bonus 2…* and lesson questions as *Warm Up*, *Example 1*… Options:
- **Show unit and standards on the answer key**
- **Show my notes on the answer key** (notes never print on student copies)

## Download as a file: Word, PDF or print

The **Format** menu in the print bar (PDF, Word, LaTeX, Print…) chooses what the buttons do:

- **Word (.docx)**: the buttons say **Download…** and save one Word file you can edit, named for what's in it (for example `Geometry Quarter 1 – Unit 3 Exam - tests and keys.docx`). Each version, the accommodated copy and each answer key starts on a new page with its own page numbers and headers. Segment and arc marks, fractions and square roots are real Word equations, and pictures and tables come along. It opens in Word, Pages, Google Docs and LibreOffice.
- **LaTeX (.tex)**: downloads a `.zip` with the LaTeX file (the standard `exam` class) and an `images` folder with the pictures. On Overleaf, choose **New Project → Upload Project** and pick the `.zip`; it compiles with Overleaf's default (pdfLaTeX). Math marks, fractions, roots and symbols like ∠ △ ≅ are real LaTeX math, and the font is TeX Gyre Schola, a free Century Schoolbook look-alike.
- **PDF**: for now this opens the browser's print window. Choose **Save as PDF** as the printer. A one-click PDF download is coming.
- **Print…**: the browser's print window, for printing straight to paper.

Downloading saves the test in **Saved tests** too, just like printing.

## Accommodated copies

For a student with an IEP or 504 plan, open **Accommodations** on **Build & print** and tick **Also print an
accommodated copy**. Then choose:

- **Font**: **Atkinson Hyperlegible** (very clear letters) or **OpenDyslexic**, or the same as the test. Both fonts are built in, so they print the same on any computer.
- **Text size**: Large (14 pt) or Extra large (18 pt). Pictures and answer spaces grow to match.
- **Questions per page**: as many as fit, 1 or 2.
- **Extra spacing**: more room between lines, answer choices and questions.
- **Make it from**: which version to copy (A, B…).

The accommodated copy has exactly the same questions and answer order as that version, so **that version's
answer key works for it**, and the key says "also the accommodated copy". Nothing on the student's copy says
"accommodated". Check it with the **Accommodated** tab in the preview (dashed lines show where new pages
start). **Print tests + answer keys** includes it; **Accommodated only** prints just that copy.

## Preview

The preview on **Build & print** sits right under your list of questions and updates as you change settings. Use **Show answers** to preview the key marks, **A / B / C…** to look at each version, and **↻ New scramble** (next to the version letters) for a new shuffle.

The print buttons are in a bar at the bottom of the preview. It stays in view while you scroll through the paper and shows what you're about to print, like "3 versions · 12 questions · 26 points". Check the paper, then print.
